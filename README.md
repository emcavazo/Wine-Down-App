# Wine Recommender

A data science project that recommends wines based on wine attributes such as description, variety, and points awarded by tasters. Built as part of my data science portfolio.

## Motivation

I work as a server and wanted to build something that could help recommend 
wines to customers based on their preferences and in turn, give them a better scope of what they might enjoy next
